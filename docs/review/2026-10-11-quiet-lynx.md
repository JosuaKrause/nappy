# quiet-lynx — Lose a run in each mode · 2026-10-11

Start a new game with Hard Mode left unchecked, play past day 4 and lose every nerve. The summary
should say "Your nerves gave out. Back to day 4." and continuing should put you on day 4's morning
with five nerves and nothing that happened after it. Then hold restart, check Hard Mode on the title
and lose every nerve again: that run should end on GAME OVER. Is the checkbox easy enough to find and
to tap on the phone? Do the "back to day N" lines read right? `--hard` and `--nerves 1` reach either
ending quickly. The build is recorded in [quiet-lynx](../decisions/2026-10-11-quiet-lynx.md).
