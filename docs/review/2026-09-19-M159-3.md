# M159 — Record the phone again with the split draw · 2026-10-04

Once the next release is out, record a stretch on the phone the way the last one was recorded
(`?debug=1&framerecord=1`, then the page's save button) and send the file over. It now splits
drawing into the game's own redraws (`draw`) and the renderer's work (`render`), counts the redraws
by kind, and says whether the browser reports the engine's own render time. The question it answers
is which half of the phone's drawing time is worth making cheaper. Record is
[M159-7](../decisions/2026-09-19-M159-7.md).
