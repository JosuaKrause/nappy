# minty-quail — Tuning's single-owner constants of the crowd and the city move to their owners · 2026-11-01


minty-quail's `tuning.md`, part B1: the constants exactly one source file reads, where that file is under
`src/crowd/` or `src/city/`, move into it.

**Built.**
- 65 constants moved, each as a `const` in its owner with its doc comment and its value unchanged, none
  renamed: 21 into `CityGenerator`, 1 into `BuildingShadows`, 6 into `StreetTrees`, 5 into `City`, 13 into
  `Crowd`, 3 into `CarStrategy`, 11 into `WalkerStrategy`, 1 into `CrowdLanes`, 2 into `CrowdExcitement`,
  1 into `CarTurn` and 1 into `Blackout`.
  Every use is rewritten, tests and probes included (`Owner.NAME` outside the owner, `NAME` inside), as are
  the docs that named `Tuning.NAME`. Doc comments left in `tuning.gd` that name a moved constant say
  `Owner.NAME`, and the moved comments name what stayed behind as `Tuning.NAME`.
- **The rule for tests.** Only files under `src/` count toward ownership, and a comment is not a read; the owner
  is the one source file that reads the constant, and a test that also reads
  it follows the constant to that owner rather than keeping it in `Tuning`, since a test may depend on any
  source file and the number is that owner's. A constant that only tests read has no owner and stays.
- **What stays although one file reads it.** `CALM_ZONE_BLOCKS`, `DEGRADATION_FIRST_DAY`,
  `CROWD_PEDESTRIANS_PER_ACT` and the three `SIGNAL_*` timings, because functions of `tuning.gd`
  (`sleepiness_gain_calm`, `degradation_for`, `crowd_pedestrians`, `signal_cycle_seconds`) read them and
  `Tuning` may not depend on a file in `src/crowd/` or `src/city/`.
- The balance skill and `docs/MECHANICS.md` no longer say every balance number lives in `tuning.gd`: a number
  two or more files read does, a number one file reads is a `const` there.
- The item lists the remaining 98 single-owner constants by owner file, under `src/events/`,
  `src/resistance/`, `src/player/`, `src/day/`, `src/routes/`, `src/interior/`, `src/finale/`,
  `src/visuals/`, `src/world/` and the root of `src/`.
