# M225 — All counting on one site, sessions for the page visit only · 2026-09-26

*([2026-09-26-curly-quail](../playtests/2026-09-26-curly-quail.md): "would it simplify things if all
telemetry only went to nappy?" · "the only benefit from the josuakrause counter is that it has
sessions" · "okay, I can turn session back on and you opt out for everything except
/nappy.josuakrause.com/" · "sessions is back on".)*

**Replaces** the split in [M225](2026-09-26-M225.md), before it was released: the game's events on
`nappy.goatcounter.com` with sessions off, and the page visit on `josuakrause.goatcounter.com`
through a script-built pixel, since one copy of `count.js` talks to one site. The old site's only
benefit was sessions, and GoatCounter's `count.js` can opt a single hit out of them.

**What is built.** One `count.js`, on `https://nappy.goatcounter.com/count`, whose site now has
sessions on. It counts the page visit itself on load, under the path `location.host +
location.pathname` (`nappy.josuakrause.com/`, as the old site recorded it), with a session, so the
visit count is visitors. Every game event is sent with `no_session: true`, which `count.js` sends as
`ns` and GoatCounter counts as a hit of its own, so repeated attempts at a day show as repeated
counts. Nothing is sent to `josuakrause.goatcounter.com`, which keeps only the history from before
this change; the pixel and its hand-written filters are gone, since `count.js` already skips
`file:`, frames, localhost and private ranges, prerendered and hidden tabs until they are seen, and
the owner's `skipgc` opt-out. `?debug=1` still loads nothing.

**Choices made where the player was silent, open to overturn**: the visit's path is host plus path
with no query string (the query arrives in its own field); the screen size is `count.js`'s own
(width only, where the pixel sent width, height and pixel ratio); a WebDriver browser is sent and
dropped by GoatCounter as a bot rather than never sent; where reading local storage throws, nothing
is counted, where the pixel would have counted the visit; the funnel in `tools/goatcounter.sh` does
not print the visit count, which `--raw` shows, because the visit's path does not carry the `nappy-`
prefix the funnel reads.

Verified by a Node run of the page's head script with the live `count.js` on top (the visit goes out
as `p=nappy.josuakrause.com/` with no `ns`; an event goes out with `ns=true`; `?debug=1` sends
nothing), a test that every one of the counter's events carries `no_session`, and the counter's and
telemetry's suites. Not yet seen in a real browser on the published page; that is the review item
for the release.
