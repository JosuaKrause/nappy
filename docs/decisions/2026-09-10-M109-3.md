using rooftop reference photos for equipment variety rather than reproducing the roof SVGs one
for one ([tawny-yak](../playtests/2026-09-30-tawny-yak.md)). The player explicitly permits these
assets to be generated without base SVGs. This is a scoped exception to SVG-first authoring,
not a change to other families.
