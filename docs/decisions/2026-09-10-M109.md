# M109 — The first dog PNG review batch · 2026-09-27

The player asked, "let's start on the svg to png item which graphics should we convert first?"
The proposed first preview was both dogs, all facings and both stride frames, enlarged and at
gameplay size. The player answered "okay", then "commit push and create a pr for the first
batch when it's ready for review". The source animals had already been accepted in
[PLAYTEST-124](../playtests/PLAYTEST-124.md), statement 7.

The batch preserved one built-in image-generation output per dog family, all twenty native
candidates, source mappings and hashes, exact prompts and reference roles, extraction and assembly
recipes, and source/PNG comparison sheets under
[comic-dogs-2026-09-27](../evidence/comic-dogs-2026-09-27/README.md). The sheets showed both
stride frames and all eight runtime facings, including west mirrors. Two assembled A/B loops
exposed pose differences; they were not gameplay captures. No runtime assets or bindings changed.

The first extraction used equal-width grid cells and any nonzero alpha for bounds. Review found
neighbor fragments and low-alpha dust enlarging those bounds, artificially shrinking the dogs.
The corrected recipe selected explicit object cells, used alpha above 10 only to measure framing,
kept a two-pixel edge pad and original alpha inside each crop, and used a shared scale for each
view's A/B pair. It did not repaint the images or impose the SVG silhouette.

The remaining body/head drift between stride frames was retained and reported, especially in side
and diagonal views. Visual acceptance, pose correction and runtime installation were left open.
The framing threshold, padding, shared pair scale, Lanczos reduction and synthetic 450ms loop
interval were agent choices, open to overturn after review.

Verification passed the twenty-pair hash/dimension/alpha integrity check, the headless import and
boot check, doc/XML lint and whitespace validation. The evidence-only scope required no runtime
suite or windowed capture. The reviewer-facing images and loops were embedded in PR 406 with
commit-pinned URLs.

The player's review in [velvet-dolphin](../playtests/2026-09-27-velvet-dolphin.md) accepted the
pursuing dog and identified static hind legs in the normal dog's E/W and SE/SW views and a
vanishing leg in NE/NW. The next pass was limited to those walked-dog stride defects on the same
PR. The accepted pursuing family was frozen; the reviewed first-pass walked images stayed beside
their evidence with the verdict, as the rejected-graphics skill requires for an in-review candidate.
