# minty-quail — The second third of the parked probes are typed · 2026-11-12

**The ask.** Test code is typed as the code it tests is ("we type when we can", inbox #1280 in
olive-ferret), and a test reads its subject only through methods (inbox #1182 in gray-dolphin):
`typed-everywhere.md`, one pass per module. This pass is the second third of the parked probes under
`tests/probes/`, the measurements run by path and never by the runner or CI, from `m128_park_beats` to
`m213_far_end`. Its search is none: it types and deletes lines and converts no read.

## What was built

- **Twelve probes parse without their file-level opt-out line**, which each loses: `m128_park_beats`,
  `m129_walked_sidewalk_walls`, `m159_contribution_cost`, `m159_tick_sweep_events_cost`, `m174_pass`,
  `m174_walk_beside`, `m184_route_timing` and `m213_far_end` (`untyped_declaration`); `m129_zero_cost_line`
  (`untyped_declaration`, `unsafe_method_access`); `m152_car_jumps` (all three); `m159_crowd_tick_cost`
  (`untyped_declaration`, `unsafe_property_access`); and `m207_warning_lead` (`unsafe_method_access`). No helper a
  probe loads changed, nothing under `src/`, and no check was deleted or moved.
- **Typing**: loop variables take the element's type (acts `int`, steps `Vector2i`, the probes' own enums,
  `GameEnums.StreetKind`); constant arrays are typed (`SEEDS`, `DAYS`, `OFFSETS`, `ANSWERS`, `GOLD_ANSWERS` as
  `Array[Answer]`); values the engine types too wide go through typed locals (a car's `strategy` as `CarStrategy`
  inside the car-only loop, a walker's as `WalkerStrategy`, an encounter's `"def"` as `EventDef`); the probes' own
  inner-class arrays are typed (`Array[Body]`, `Array[ClosedBand]`, `Array[Row]`), two ternaries that answered `[]`
  becoming `if`/`else`; enum parameters that took an `int` take the enum.
- **Nothing is read by name**: every `.get("…")` is a Dictionary's, and no probe writes a script out from a string.
  The probes' calls to the game's private methods (`EventScheduler._place_ambient()`,
  `CarStrategy._room_to_stop_in()` and others) stay as they were. Of the methods paired with a write, only
  `Crowd.use_player()` sets the value a probe chooses (`_player = player`), and could stand in for the probes'
  `crowd._player` writes in a later conversion.
