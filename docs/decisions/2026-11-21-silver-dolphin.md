# silver-dolphin — The orchestrator checks the board hourly, files the inbox on its own, and waits instead of ending · 2026-11-21 · not from an entry

**What the player asked** (inbox #1619 in teal-dolphin): that the orchestrating session reads the board about every hour on its own, files the inbox on its own from time to time, keeps when it last checked each in a local file that is not checked in, does not end the session when it runs out of work but says so on the board and wakes at least every 45 minutes so the prompt cache stays warm, communicates through the board because the player looks at the chat rarely in code mode, and has all of this written down. Filed and built in one pull request, with no queue entry, since the work was the skill text alone.

**What was built.** The board skill reads the board at each run of the recurring check, never more than about 55 minutes apart, as well as at session start, on "doc" and before a turn's first write, and keeps its Running and Recently done tables current within that hour. The inbox skill and its filing reference let the orchestrating session file open notes on its own as well as when asked; playtest-feedback says the same. The orchestrating skill keeps the session open when it is out of work: a line on the board says so, and the recurring job, about every 30 minutes for the whole session, wakes it to look for new work and carries the agent check, the board read at each run, the filing and the update of the times. Session-cleanup's restart prompt gains a "Last checked" section.

**What it replaced.** The board was not polled between turns (inbox #830 in minty-dolphin), the player giving a heads-up when it mattered. A batch was filed only when the player asked (bouncy-heron 6, built by the record leafy-finch). The session ended when only work waiting on the player was left, and the recurring job was deleted when no agent ran; that was the filer's proposal, which the player's words now overturn.

**Proposed, not asked for**, each in its skill's list: the hourly read as each run of the 30-minute job so that no gap passes about 55 minutes (the hour meaning under 55 minutes is the player's, inbox #1621 in teal-dolphin), filing on the same beat, the out-of-work note as the line under the Running table, what the 45-minute wake looks at.
