## M171, the events — built 2026-09-20

A consumer move of the milestone, pull request #255. The agent that began it was cut off by a
usage limit twelve minutes in, with nothing run; a second agent took over its uncommitted
worktree and finished the item.

**Built.** Every picture in `event_instance.gd` is a repository path rather than a `preload`;
`_drawn(picture)` hands a draw the `AtlasLibrary.region()` of `region_name_for(path)` through
a static path-to-name cache, and `_native_size(picture)` answers a size asked outside a draw
from the region table with nothing loaded. Tints, the crash's separate contact-shadow region
and every view, stride frame and mirrored view are unchanged; `icon_for()` and the four other
selectors answer `""` where they answered `null`. `EventManager` takes one
`acquire(&"events")` in `_enter_tree()` and one `release()` in `_exit_tree()`, which replaced
`_match_the_atlases_to_what_is_live()` and its six call sites. `events` is in `main.gd`'s
`RESIDENT_GROUPS`. `DangerEdge._icon_for()` answers a region name, so the screen-edge badge
and the street draw the same pixels. The six `poster_crew_square` pictures are members of the
`events` group, and `tools/bake-atlases.sh --check` reports the tree stale for that edit.

**How the scripted rewrite was checked.** The first agent converted the tables with a script.
Every `res://assets/…` string was extracted from `origin/main`'s file and from the new one:
267 occurrences in each, in the same order with the same multiplicities, 267 `preload(`s
became none, and the baked `events` group carries exactly 267 regions. What the script missed
were five `_draw_spread(PICTURE, null, canvas)` call sites whose cap parameter had become a
`String`, so the file did not compile until they passed `""`.

**`""` is never equal to `null`.** `_wide_scene_shadow()` answers `""` where it answered
`null`, which turned the fallen tree's `== null` check red and would have left the crash's two
`!= null` checks passing with the function deleted. All three ask `is_empty()`; a sweep of the
event suites found no other check of that shape.

**Measured.** `[Main] N atlas pages held from startup in N ms` over five headless boots: nine
pages in 16–25 ms, against eight in 8–12 ms with `events` taken out of the list. The page's
own read is 8.7–10.9 ms, and the page is 582×936.

**The runtime packer's suites stand on no family.** `test_texture_atlas.gd` packs four prop
pictures loaded by path and `test_telemetry.gd` builds two `ImageTexture`s, because inputs
read off whichever family had not moved yet broke each time one did. `test_visuals.gd`'s warm
audit walked `event_instance.gd`'s constants for `Texture2D`s and would have passed vacuously
on the empty map; it asks the same question over its own nine rig transfer pairs.
`test_event_manager.gd`'s two runtime-packer tests are deleted, since there is no per-family
group left to ask about.

**What the runtime packer and the resolver still have as callers**, for the item that deletes
them: `TextureAtlas` — `main.gd`'s per-frame `collect_ready()`, and `collected_count()` in
`telemetry_observer.gd` and `frame_trace.gd`; no production caller asks it for a group.
`TextureResolver` — `sprites.gd`'s `resolve()`, `main.gd`'s `warm()` and the telemetry
counter. `TextureResolver.warm()` loads 116 individual pictures at boot (the `props`, `rig`
and `tiles` transfers) whose consumers draw from baked pages.

**Not seen.** No capture could arrange a screen-edge badge, which needs something lethal off
screen and closing; `tests/test_atlas_events.gd` checks that the badge's pictures resolve.

**Open to overturn.** `_native_size()` returns a `Vector2`, a drop-in for the `get_size()` the
call sites asked of a texture; `family_sources()` returns a sorted `Array[String]` and is read
only by the new suite.
