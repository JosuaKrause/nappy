# minty-quail — The run flow's, the save's and the day's suites are typed · 2026-11-11

**The ask.** Test code is typed as the code it tests is ("we type when we can", inbox #1280 in
olive-ferret), and a test reads its subject only through methods (inbox #1182 in gray-dolphin):
`typed-everywhere.md`, one pass per module. This pass is the run flow; its search covers `RunFlow`, `DayController` and
`GameSave`.

## What was built

- **Eight suites parse without their file-level opt-out line**: `tests/test_run_flow.gd`,
  `test_run_checkpoints.gd`, `test_day_loop.gd`, `test_run_state.gd`, `test_save_wiring.gd`,
  `test_invincible.gd` and `test_park_return.gd` (`unsafe_method_access`), and `test_day_controller.gd`
  (`untyped_declaration`).
- **Typing**: a booted main handed to `Boot.boot`'s `before` callable is `Boot.MainScript`; the day summary's
  root is `Boot.DaySummaryScript` and the HUD's its preloaded script; loops take their types.
- **Reads converted to methods the game calls** (`DayController`, each body `return <field>`):
  `time_remaining` → `seconds_left()`, `failure_reason` → `loss_reason()`, `exit_reached` → `exit_taken()`.
- **Left**: `DayController.phase` (the checks ask for each phase; `is_running()` answers only `phase != OVER`),
  `hard_fail_reason`, `spec` and `invincible`, no method; `RunFlow.mode` (`in_the_title()` answers one mode, the
  suite asserts every mode) and `authored` (`escape_follows()` asks the opposite question), and `scene`, `spec`
  and `opening`, no method; no field of `GameSave` is read. `RunState`'s parts stay read through `run.header`
  and the like, for the third hand-ins step. No check deleted or moved; nothing under `src/` changed.
