# minty-quail — The row's suites test the row (row 5, first group) · 2026-11-22

**What was asked.** Row 5 of minty-quail's `event-interface.md` converts the events' and the resistance's suites to test
one module each, one pull request per group (`tests-one-module.md`, entry 6; no test builds a real object it does not
test, a suite tests the module it is named for, tests become faster, and the city is never built for a test that does
not test it, inbox #1156 and #1159 in gray-dolphin). Its first group is the row's suites: the catalogue, costs,
emission, solid ground and acts, asserting only relationships between a row's settings. Built as #1645 by two Sonnet
agents.

**What was built.** Every case in the five suites that built a live event, a city or a node, or generated a city map
and planned a day, left them: a case about a live event's phases to the phase suite, the drawing cases to the views
suite, the burnt building to the city's buildings suite, the pram's size to the stroller's, where a body stands to the
stance's suite, and the fifteen cases that planned days unchanged to the dawn's suites (the scheduler, placement and
spacing), where the dawn group converts them; the protest's role and its swell are asked of the row, with the live
swell kept beside the leaf blower's in the phase suite. Two checks that duplicated the stance suite's were dropped.

**Rejected.** Keeping the cases that generate a city map and plan a day in the row's suites, treating the map as a
plain value: the first build did so, and the review held that such a case tests the dawn's question, not the row's,
by the design's words, writing-tests' list of slow setups a mock replaces, and the player's that the city is never
built for a test that does not test it; those cases were nearly all of the suites' time.

**Measured.** On CI, the five suites took 215.9 s on main and 2.4 s on the branch; the dawn's suites that took the moved
cases grew by about as much, so the total is unchanged until the dawn group mocks them.
