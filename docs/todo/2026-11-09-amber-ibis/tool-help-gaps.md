# A tool's help says what its catalogue row had to keep

The tool catalogue (the using-tools skill) says what each entry point is for and leaves flags,
numbers and refusals to the tool's `--help`. For about two dozen tools the help does not say
something the old row said, so the row keeps that sentence; the record of the catalogue's rework
(sandy-alpaca) lists them, among them `tools/goatcounter.sh` (a saved read is compared against the
previous file in its folder; where the key comes from; a linked worktree reads the main checkout's
`.env` after its own), the layer, override, field-read and citation checks, `tools/inbox.py` and
the CI checks. Six tools that write pictures or video print no pointer to the skill that governs
their output (`tools/remove-checkerboard.py`, `split-scenes.py`, `bake-atlases.sh`, `record.sh`,
`clip.sh`, `trailer.sh`).

**Build:** each tool's `--help` says what its row still carries, and the row loses it; the six
tools print the one-line pointer the others print.
