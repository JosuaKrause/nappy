**Every review item under `docs/review/` is read against the code, the records and the playtest it came from**, the way the queue was audited: built, superseded, partly built or still open, with the evidence for each. The ones that no longer apply, or whose question a later playtest answered, are listed for the player with a proposal to close or reword them; none is dropped silently (**playtest-feedback**: a review item's file goes only when a playtest has answered it). The ones that still wait on a person are rewritten in full so each states what to do, where to look and the question a run answers.
