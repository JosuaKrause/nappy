# A body's point is stood once

Either the two live callers hand the record the point the body was built at rather than where it now stands, or
`BodyStance.stands_at()` returns an already-stood point unchanged. The builder reads both callers and `stands_at()`
first and says which keeps every other caller's answer; the filer's pick is `stands_at()` made idempotent, since a
function that moves a point it has already placed is a trap for the next caller too. A suite holds it: standing a
stood point of each of the eight rows gives the same point. The record of a live body's tiles then matches the body on
the probe cities (curly-stork's sweep, `tests/probes/curly_stork_piece_layout.gd`, once it exists, or the design's
scratch probe), and what a guard's or a pursuer's line of sight leaves out of its own body is said in the pull request,
with pictures if a sight line a player can see moves. It starts after curly-stork's pull request, which owns the same
files.
