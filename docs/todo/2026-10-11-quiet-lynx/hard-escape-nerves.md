# The escape spends and regains nerves in hard mode

The days in hard mode are exactly today's rules: 0 nerves gives the bad ending (GAME OVER), and the
save is deleted. The escape is where hard mode differs from normal (statement 1: *"with hard mode the
escape also has normal nerve counts and ends if nerves go to zero (instead of restarting
indefinitely; this is only for normal mode)"*). In hard mode:

- she enters the escape with the nerves day 14 left her;
- a lost section (being taken, the meter reaching 100, or the clock running out) costs one nerve;
- clearing a section, "Escape the building", gives one back (statement 3, answer 3: *"Section won
  gives one back"*), before "Escape the city";
- 0 nerves ends the run with the bad ending.

**Proposed, not asked for:** the regained nerve is capped at 5, the starting count, as a won day's is.

**Normal mode's escape is unchanged**: a lost section costs no nerve and starts again where it began,
indefinitely, as `docs/MECHANICS.md` says ("A lost section starts again where it began, and costs no
Nerve").

This **narrows an earlier word of the player's to normal mode, at the player's own word**:
pebbly-penguin, statement 3 ([pebbly-penguin](../../playtests/2026-09-27-pebbly-penguin.md)),
*"escape doesn't have nerves"* · *"escape has no nerves was already preexisting you should have it in
your records"*, and the M102 record: *"Losing the finale restarts the section, at no Nerve cost."*
("sounds good at that point you earned it.") The reason it stood, that a fourteen-day run is never
thrown by one wrong turn in the last minutes, is what normal mode keeps; hard mode is the player
choosing to have that wrong turn count.

`docs/MECHANICS.md` "Nerves" says *"The escape gives none back"* and "A lost section starts again",
and both gain the hard-mode rule in the same pull request.
