**Is the nerve economy right?** Five since M35, and **asked for rather than derived** — the
thing that made three too few was a defect rather than a difficulty, so if act I now reads as
fair, five may be generous. The other side is still open: with five attempts and a retry
costing only time, **is a lost day a punishment at all?** Both modes are in the question. In hard
mode a won day gives no nerve back and the last nerve ends the run with the bad ending, so five
attempts are all the run has. In normal mode a won day gives a nerve back (up to five) and the last
nerve sends the run back to its latest checkpoint's dawn with five nerves again, never to the bad
ending, so a normal run is never lost to nerves at all.
