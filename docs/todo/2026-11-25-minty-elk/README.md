# minty-elk — The resistance package's meter multiplier was never re-derived with the streets' · filed 2026-11-25

**The question.** `City.RESISTANCE_PACKAGE_DECAY_MULTIPLIER` (0.5) is how much slower her excitement
meter falls for the rest of the day once she carries the resistance's package (the pram heavier, a
decision she made rather than ground she crosses). It was set on the same severity as a main road's
own multiplier then, 0.6. M117 then raised the walking decay and re-derived every ground's multiplier
to keep each ground's absolute rate: the main road's went from 0.6 to 0.35 and is now 0.02, an
alley's is 0.58. The package's multiplier was not re-derived and now sits near an alley's, far above
a main road's. Nothing re-derives it when the ground multipliers move.

**Whether it should move is the player's word**, since a cost the player feels moves only on their
word. **The entry asks the player when it is picked up** (the filer's proposal), on the board
(**board**), with the measured cost of a day carrying the package at 0.5 against the main road's 0.02
and an alley's 0.58, and what each choice costs; it changes no number before the answer.
