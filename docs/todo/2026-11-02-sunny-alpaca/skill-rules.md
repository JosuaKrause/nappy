# The skills say how work survives an interruption

**Build:** **orchestrating** says an orchestrating session keeps its in-flight state where a fresh
session finds it, and its own working state in the local restart prompt, written during the session
whenever it is cheap to; **session-cleanup**'s restart-prompt step says the same file is kept
current during the session, and its end-of-session pass rewrites it whole; **board** says the board
is the player's information and their channel to answer, and that its Running table is updated in
batches rather than at every merge or verdict. Each rule cites inbox #986 in brisk-pelican.
