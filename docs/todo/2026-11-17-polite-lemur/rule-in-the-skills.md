**orchestrating**'s bullet on a defect a refactor step finds, and its "Proposed, not asked for" entry
that names `now` as the band with `bug` only where the player moves it (the orchestrator's pick on
the board question `refactor-bug-band`), say instead that such a defect is filed `bug` and started
at once beside the refactor, citing inbox #1519 in breezy-magpie. **playtest-feedback**'s "`bug` is
never proposed or defaulted, for any entry: it is filed only when the player names it" and the
inbox skill's matching line gain the exception the player named: a bug a refactor step finds. The
record spotted-trout, which wrote the rule with the pick, is left as it stands; the pull request's
own record says what changed.

*Proposed, not asked for:* "bug" read as the code doing what the player's decisions or the docs
say it should not, the board's wording; a finding the investigation shows is not one (a probe or a
doc that is wrong) leaves the band.
