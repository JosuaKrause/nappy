# The arrow that points home, and to the day's task, is a picture

The arrow points the way home during the return, and a second instance points to the day's
resistance task. Both are drawn in code as a filled polygon with an outline
(`HomeArrow._draw_chevron()`, `src/ui/home_arrow.gd`).

**Build:** one image file under `art/`, rotated to point at its target, for both arrows; the
task's arrow keeps its red.
