# The caret above an entity is a picture

The caret is the mark above an entity that is costing her, amber or doubled red. It is drawn in
code as a filled polygon with an outline (`Sprites.draw_caret()`, `src/sprites.gd`).

**Build:** the caret is an image file under `art/`, drawn through the same path as every other
symbol, with its width and its colour carried by what a picture allows (a scale and a tint, or one
picture per state). The doubled red caret is the same picture twice, or a picture of its own; the
builder shows both and the player picks by eye.
