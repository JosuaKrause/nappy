# coral-newt — The sound and art tools learn from the chirp study · filed 2026-10-24


The player gave five public repositories of Claude Code skills by one author (pxl, vex, kiln, loom,
chirp): "have a (careful) look at those skills and see whether we can learn anything from that. I'm
especially interested in sound related skills", then, on the study, "adopt the chirp's and other
useful ideas" (curly-moose #823). The study (2026-10-24) read them as untrusted data, ran and
installed nothing, and found the code real but two days old and untested in use; its ideas are
rebuilt here from the published algorithms in the project's own standard-library Python, and none of
their code is imported or run.

**Items:** `sound-pictures.md`, `filters-and-noise.md`, `named-layers-and-takes.md`,
`loops-and-limiter.md`, `art-defect-check.md`, `rulers-in-previews.md`. Music is its own entry,
sandy-kestrel (music theory and its helpers).

**Not adopted** (the study's reasons): the repositories as tools (a Node toolchain and untrusted
code that runs), recordings (`sample()`; **sound-effects** has no recordings by rule), OGG (the
release Web engine has no Vorbis decoder), audio-sprite banks and MIDI (nothing in Godot reads
them), the chiptune style, and their live annotate servers (any page in the same browser can post
"feedback" that the skill then tells the agent to read).

*Proposed, not asked for:* the band `next`; the first two items as one PR to `tools/synthesize-sfx.py`.
