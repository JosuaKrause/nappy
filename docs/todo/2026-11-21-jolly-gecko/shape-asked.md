# A ground shape is asked, not read

The shape answers what its readers read off it (its kind's questions, its reach, its extent along and across an axis),
its four fields go private, and the one test that changes a shape in place builds a second shape instead; the
excitement source's cache key holds the shape itself once the shape cannot change. Nothing a player sees changes:
`tests/probes/row_fingerprint.gd` and `tests/probes/look_fingerprint.gd` print the same on base and branch.
`crowd-traffic` governs `src/ground_shape.gd`, which the car's driving reads.
