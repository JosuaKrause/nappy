# Apartment graphics runtime review — 2026-09-12

This folder preserves the complete telemetry run plus the `review/` stills from the same
display-backed Godot process. The capture uses the current apartment source changes over the
base revision named by the run folder, seed 4242, a 1280×720 viewport and normal player camera
zoom. It has no invincibility override; the apartment test has no finale hazards or clock.

`review/` holds all seven room parts, both flight directions and lower landings in each shaft,
and the basement entry, middle and exit. Stills position the actual player and camera directly
to inspect rendering; they do not prove that the player walked between rooms.

`asked/burst-6944956-001` records the left stairwell and `asked/burst-11132409-002` the right.
Each starts on the first diagonal flight cell, follows the existing cell centers using real
input and physics, turns at the half-landing and continues onto the return flight. The rig
subsequently reaches the second-floor landing within 4px of its center in both shafts.
The original numbered frames and `burst.json` files carry the actual timing. Sibling MP4s are
generated by `tools/clip.sh`. Read frames in numerical order; each burst lasts about three
seconds and covers both flight directions. The control-feel verdict belongs to a human playtest.

`escape_graphics_review.gd` and `.tscn` preserve the scratch rig exactly. To reproduce, copy both
to `/private/tmp/` and run Godot with this project, the copied scene, `--resolution 1280x720`,
and user arguments `--start-escape --seed 4242`. It writes stills to
`/private/tmp/escape-graphics-review` and bursts to the new telemetry run. The code bounds each
physical leg and exits nonzero if it stalls. The telemetry's `(0,0)` context and zero log clock
are the apartment mode's generic capture context; actual movement is visible in the frames.
