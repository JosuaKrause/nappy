# Rejected water-main and fallen-tree transfers

These 28 PNGs are the byte-identical runtime transfers rejected by the player in
[bouncy-squirrel](../../../../playtests/2026-10-03-bouncy-squirrel.md), quoting the
September 30 review of PR #441. They are preserved for historical comparison only,
not style references or assets to reinstall.

The nested `art/illustrated/svg-transfer/` paths retain their original identities.
Their generation prompts, raw inputs, registration recipe and hash manifest remain
in [the obstruction family evidence](../../../obstruction-pngs-2026-09-30/GENERATION.md).
The source is PR head `980f1cec25be038c4f5055b031f63c034d5094ab`; moving the files
checks all 28 hashes before and after. Existing SVG files and their animation-layer
bindings supply the runtime pictures when these transfers are absent.
