# Playtest golden-otter — The newest save action decides what the save symbol shows

2026-10-02.

Not played; the player's answer to a reviewer's finding on the save symbol (rosy-chipmunk, built
from [cozy-pelican](2026-10-02-cozy-pelican.md)).

## What was asked

The Codex reviewer (`nappy-codex-reviewer`) found that overlapping save actions did not follow
cozy-pelican statement 9, "Newest answer wins": the symbol tracked a batch (every save from one
begun with nothing pending until none was pending) and was struck if any save of the batch
failed, so an older save failing and a newer save kept, both answered while overlapping, left the
symbol struck. During that review the player clarified:

> "if a new save succeeds it doesn't really matter if an old save failed. only the latest save
> action matters"

The reviewer's text relayed those words; asked in the building session whether they had said
them, the player confirmed ("Yes, I said that").

## What is asked for, as statements

1. **Only the newest save action decides the symbol.** Whichever save or deletion was started last
   owns what the symbol shows: plain once it is kept, struck if it was not kept. An older action's
   answer never decides it, in either order of arrival: an older failure answered after a newer
   success does not strike the symbol, and an older success answered after a newer failure does
   not clear the strike.
2. This replaces the batch rule; cozy-pelican's statement 9 ("a later save that is kept clears
   the strike") stands and is now exact about which save is "later": the one started last.
