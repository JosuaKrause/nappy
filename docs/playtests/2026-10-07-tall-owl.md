2026-10-07.

## #613 — Running offscreen counts toward shaking off a sent pursuer

The assistant asks about PR #597: an earlier review added a rule that a sent robber must be
visible for 1.5 seconds before running can shake him off. Running immediately keeps him offscreen,
so the chase lasts 30 seconds and the baby cries after about 8 seconds. The assistant recommends
allowing a sustained run to escape an unseen pursuer, while walking still cannot escape.
The offered answers are "Allow running to escape before he appears (recommended)" and
"Keep the visibility requirement; wait for him before running". The player answers:

> you mean starting to run while he's offscreen still counts towards the shaking off timer? sure

This answers the unseen-pursuer escape question. Running while the sent pursuer is offscreen
counts toward shaking him off. The standing robber's separate visible lunge warning is not
part of this question, and walking still does not escape.
