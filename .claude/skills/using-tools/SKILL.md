# Using the tools

**Everything in `tools/` is a shortcut for a sequence somebody has already typed by hand once
and did not want to type again.** This is the map: what each entry point is for, when to reach
for it, and which skill carries the detail behind it. What nobody may miss, one line each:

- **A tool's `--help` is the source of truth for its flags, numbers and refusals**; a row here says
  what the tool is *for*. Run `tools/<name> --help` before the first use.
- **Some jobs have exactly one way in**: GoatCounter through `tools/goatcounter.sh`, Reddit through
  `tools/reddit.py`, an issue through `tools/inbox.py`, a new name through `tools/new-name.sh`,
  a merged branch's retirement through `tools/prune-merged.sh`.
- **A GitHub write runs as an agent identity**, wrapped in `tools/agent-identity.py run <role> --`;
  **committing** owns which role and what the write guard denies.
- **Search with `rg`.** A `git grep` with neither `-I` nor a text-only pathspec is denied.
- **A manual sequence done a second time becomes a script**, with its row here in the same commit.

`.claude/skills/cli-tools/SKILL.md` covers what every entry point owes (`--help`/`-h`, rejection of
anything it does not understand, one place the flag list lives), not what each is for.

## What the rows do not say

**A tool that allocates a batch checks free space first.** `tools/build-web-template.sh`,
`tools/export-web.sh`, `tools/bake-atlases.sh`, `tools/scene-recipes.sh`, `tools/shot.sh`,
`tools/record.sh`, `tools/trailer.sh` and `tools/run.sh`'s import repair source
`tools/lib_disk_headroom.sh` and, after their arguments are validated and before the first byte is
written, compare the volume's available space with the batch's measured peak. Below the peak they
refuse, naming the shortfall, a smaller batch where there is one, and the worktree inventory for
cleanup; below the peak plus a reserve they warn with the same figures and run; an unmeasured job
or an unreadable `df` refuses. The library's header names the estimates and the variables that
override them. **A low-disk warning stops new work** (quiet-yak #496): **orchestrating**'s
`references/worktrees-and-disk.md` says what happens next.

**Two `PreToolUse` hooks guard every shell call, and neither is a catalogued tool.**
`.claude/hooks/git-grep-guard.sh` denies a `git grep` with neither `-I` nor a text-only pathspec,
since a search over this repository's binary-heavy `docs/` grows without bound, and denies a
mention of the two words in any command text as well: write `git-grep` for a mention, and for a
search use `rg`, add `-I`, or restrict the pathspec (`-- '*.md' '*.gd' '*.sh'`).
`.claude/hooks/github-write-guard.sh` denies a GitHub write outside an agent identity;
**committing** owns that rule ("Who a commit and a pull request are from") and how text that names
a write is handed over ("Text handed to a write goes through a file"). Each hook's header comment
is the exact list of what it denies, and each denial names the way out.

**A third guards the resume of a sub-agent.** `.claude/hooks/resume-guard.py`, on every

## A manual sequence done a second time becomes a script

`CLAUDE.md` states the rule, with the player's words. What it means here: when the same manual
sequence of shell commands — git and gh housekeeping, checking on an agent, a verification pass, a
capture, a build — comes up a second time, it becomes a script and is not retyped a third
time. The new script follows **cli-tools** for what it owes, gets its two CLI test cases in
`tools/test_cli_help.sh` or `tools/test_cli_help.py`, and adds its row to the table above — all in
the same commit, so the catalogue is never behind what it describes. **A row is about 200 bytes**:
what the tool is for, when to reach for it, which skill holds the detail. Flags, numbers and
refusal lists go in the tool's `--help`.

**The row is enforced, not remembered.** `tools/test_cli_help.sh` fails if any `tools/*.sh`
or `tools/*.py` entry point (excluding `lib_*` and `test_*`) has no row in this table, so a tool
added without its row is a red check and not a gap somebody has to notice.
