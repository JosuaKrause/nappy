# default, with a warning, rather than silently dropped.

# rewrites this file from that run's own "-- suite  N ms" lines, or with `tools/ci-costs.sh`,
# which reads those same lines out of the last few green CI runs on main and averages them
# instead -- either way never hand-edited, so the numbers come from a runner rather than from
