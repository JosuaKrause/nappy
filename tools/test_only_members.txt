# The public members only tests read, which tools/check_test_only_members.py lets stand: one
# "<file> <member>" per line, sorted within a group. A group starts at a header comment whose first
# word is its tag in brackets. The [no reader] and [own file only] groups only shrink: the check fails
# a line added to either (against the pull request's base) and a line that has gone stale, a member
# that gained a reader in another file, lost its tests, or is gone. The pull request that fixes a
# member deletes its line. A [kept] group takes a new line, and the check fails one with no reason
# after its '#'.

# use too, since a constant nothing reads is the same dead weight). Each gets a reader in the game,
# or its tests go through what the game exposes (a fake handed in, or what the game shows), or it is
# deleted.
